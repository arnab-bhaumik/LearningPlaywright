# Learning Playwright

A comprehensive learning repository for Playwright test automation framework with JavaScript fundamentals and practical examples.

## 📚 Overview

This repository contains structured learning materials for Playwright, starting from JavaScript basics to Playwright-specific concepts. The content is organized in a progressive manner to help beginners understand both JavaScript fundamentals and Playwright automation.

## 🗂️ Project Structure

```
LearningPlaywright/
├── Chapter_01_Basics/
│   ├── 01_basic-playwright.js
│   ├── 02_js-step-by-step.js
│   ├── 03_verify-setup.js
│   └── 04_hot-code.js
│
└── Chapter_02_Javascript_Fundamentals/
    ├── 05_ comments.js
    ├── 06_identifiers.js
    └── 07_var-let-const.js
```

## 📖 Chapter Details

### Chapter 01: Basics

This chapter covers the foundational setup and basic JavaScript execution:

| File | Description |
|------|-------------|
| **01_basic-playwright.js** | Simple Node.js execution test to verify the environment is working |
| **02_js-step-by-step.js** | Demonstrates variables, loops, and functions in JavaScript |
| **03_verify-setup.js** | Verifies Node.js environment details (OS, CPU architecture, Node version) |
| **04_hot-code.js** | Demonstrates repeated function execution with performance testing |

### Chapter 02: JavaScript Fundamentals

This chapter dives into core JavaScript concepts essential for Playwright:

| File | Description |
|------|-------------|
| **05_ comments.js** | Demonstrates different JavaScript comment styles (single-line, multi-line, documentation) |
| **06_identifiers.js** | Covers identifiers, literals, operators, and naming rules |
| **07_var-let-const.js** | Explains the differences between `var`, `let`, and `const` with scope examples |

## 🚀 Prerequisites

Before running the examples, ensure you have:

- **Node.js** (v14 or higher recommended)
- **npm** (comes with Node.js)
- **Playwright** (optional for basic JavaScript examples)

## 💻 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arnab-bhaumik/LearningPlaywright.git
   cd LearningPlaywright
   ```

2. **Install Playwright (if needed):**
   ```bash
   npm init playwright@latest
   ```

## 🎯 Usage

### Running Individual Files

You can run any JavaScript file using Node.js:

```bash
# Navigate to the project directory
cd LearningPlaywright

# Run a specific file
node Chapter_01_Basics/01_basic-playwright.js
node Chapter_02_Javascript_Fundamentals/07_var-let-const.js
```

### Example Outputs

**Chapter 01 - Basic Execution:**
```bash
node Chapter_01_Basics/01_basic-playwright.js
# Output: Hello! Playwright learning environment is working.
```

**Chapter 02 - Variable Scoping:**
```bash
node Chapter_02_Javascript_Fundamentals/07_var-let-const.js
# Demonstrates var, let, and const behavior with different scopes
```

## 📝 Learning Path

Follow this recommended sequence:

1. **Start with Chapter 01** - Get familiar with the environment
   - Run `01_basic-playwright.js` to verify setup
   - Explore `02_js-step-by-step.js` for basic JavaScript concepts
   - Use `03_verify-setup.js` to check your Node.js configuration
   - Experiment with `04_hot-code.js` for function execution

2. **Move to Chapter 02** - Master JavaScript fundamentals
   - Learn comment styles with `05_ comments.js`
   - Understand identifiers with `06_identifiers.js`
   - Master variable declarations with `07_var-let-const.js`
