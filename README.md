# Learning Playwright - JavaScript Fundamentals

A comprehensive learning repository for Playwright test automation framework and JavaScript fundamentals. This project provides practical examples, interview coding questions, and detailed chapter-by-chapter exercises logically segmented to build strong foundations in JS.

## 📚 Overview

This repository contains structured learning materials aimed at helping beginners understand core JavaScript concepts before diving fully into Playwright automation. By following the chapters sequentially, you will grasp everything from basic variables and scopes to complex conditional logic, switch statements, and loop structures.

### 🟢 Chapter 01: Basics
This chapter covers the foundational Node.js and Playwright setup, along with basic JavaScript execution.
- Includes setup verification, step-by-step JS introduction, and basic execution performance.

### 🟡 Chapter 02: JavaScript Fundamentals
Dives into the core language features essential for understanding test frameworks.
- **Key Concepts:** Best practices for comments, identifiers, and the strict differences between `var`, `let`, and `const` variable scoping.

### 🔵 Chapter 03: Identifiers, Literals & Type Operations
Explores the building blocks of JavaScript expressions and state comparison.
- **Key Concepts:** Literals, `null` vs `undefined`, using the `typeof` operator, and understanding the critical difference between loose equality (`==`) and strict equality (`===`), featuring interview questions.

### 🟠 Chapter 04: Operators
Focuses on evaluating logic and manipulating data using varying JS operators.
- **Key Concepts:** Assignment, Comparison, Logical, String, Ternary operators, and handling Null optional values.

### 🟣 Chapter 05: Statements
Learn how to branch logic using conditional statements through applied real-world examples.
- **Key Concepts:** `if`, `else if`, `else`, user login validations, API validations, and conditional branching interview challenges.

### 🟤 Chapter 06: Switch Statements
Deep dive into alternative logic branching when dealing with multiple specific conditions.
- **Key Concepts:** Core Switch functionality without/with `break`, `default` fallbacks, grouping cases, and tackling common switch-related bugs and interview scenarios.

### 🔴 Chapter 07: Loops
Automate repetitive tasks and iterate over data using JavaScript iteration techniques.
- **Key Concepts:** `for` loops, `while` loops, `do...while` constructs, and correctly applying increment/decrement (`++`, `--`) operators.

### 🎯 Task: Interview Coding Questions
A dedicated section for putting theory into practice with real programming challenges often seen in interviews.
- **Challenges Included:**
  - Grade Calculator System
  - Fizz Buzz Challenge

## 🚀 Prerequisites

Before running the examples in this repository, ensure you have the following installed:
- **Node.js** (v14 or higher recommended)
- **npm** (comes bundled with Node.js installer)
- **Playwright** (optional but recommended for later testing chapters)

## 💻 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arnab-bhaumik/LearningPlaywright.git
   cd LearningPlaywright
   ```

2. **Install Playwright (if setting up the environment for automation):**
   ```bash
   npm init playwright@latest
   ```

## 🎯 Usage

Most JavaScript tutorial files are standalone and designed to be executed individually using Node.js:

```bash
# Navigate to the project directory
cd LearningPlaywright

# Run a specific file from a chapter
node Chapter_01_Basics/01_basic-playwright.js
node Chapter_07_Loops/54_Incremnt_operator.js
node Task_Interview_Coding_Questions/02_fizz_buzz.js
```
